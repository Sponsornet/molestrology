# 🔮 Molestrology Bot

Telegram-бот, который анализирует родинки на фото через Gemini AI и рассказывает о них как о звездной карте.

## Возможности

- 📸 Анализ фото родинок
- ✨ Мистическое предсказание
- 🔊 Голосовое сообщение (TTS)
- 🇺🇦 / 🇬🇧 Два языка

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# отредактируй .env
python molestrology.py
